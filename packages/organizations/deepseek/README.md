# llm-api-adapter-deepseek

Official direct DeepSeek API support for
[llm-api-adapter](https://github.com/Inozem/llm_api_adapter/).

This independently versioned package targets Core `0.9.6` and adds no
DeepSeek SDK dependency. Detailed model, capability, file, reasoning, pricing,
and release-contract documentation will be maintained here as the integration
is implemented.

## Installation

```bash
pip install "llm-api-adapter[deepseek]"
```

Direct installation is also supported when Core is managed separately:

```bash
pip install llm-api-adapter-deepseek
```
